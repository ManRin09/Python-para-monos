# 🐒 Python para Monos

Bienvenido a **Python para Monos**, un repositorio diseñado para entrenar tu lógica de programación en Python de forma progresiva. El objetivo de este material es llevarte desde las bases absolutas hasta la capacidad de construir scripts avanzados que resuelvan problemas del mundo real.

## 📂 Estructura del Repositorio

El aprendizaje está dividido en tres niveles, cada uno con 10 ejercicios prácticos, culminando en un proyecto de automatización. 

### 🟢 Módulo 1: Fácil (Fundamentos de Lógica)
En este módulo afianzaremos las bases. Aprenderás a controlar el flujo de información, tomar decisiones y repetir acciones.
1. `01_hola_tipos.py`: Declaración de variables y tipos de datos.
2. `02_calculadora_basica.py`: Operadores matemáticos y lógicos.
3. `03_control_acceso.py`: Uso de condicionales (`if/elif/else`).
4. `04_contador_vocales.py`: Ciclos `for` e iteración sobre cadenas.
5. `05_adivina_numero.py`: Ciclos `while` y control de estado.
6. `06_inversor_palabras.py`: Manipulación básica de strings (slicing).
7. `07_lista_compras.py`: Introducción a listas y métodos (`append`, `remove`).
8. `08_buscador_mayor.py`: Algoritmos iterativos de búsqueda en listas.
9. `09_filtro_pares.py`: Operaciones matemáticas en colecciones (módulo `%`).
10. `10_menu_consola.py`: Integración de ciclos y condicionales en una interfaz de texto.

### 🟡 Módulo 2: Intermedio (Estructuras de Datos y Funciones)
Aquí el código se vuelve modular y organizado. Comenzaremos a manejar datos más complejos y a preparar el terreno para leer información externa.
1. `11_refactor_calculadora.py`: Creación de funciones con parámetros y retornos.
2. `12_frecuencia_palabras.py`: Uso de diccionarios para contar elementos.
3. `13_agenda_contactos.py`: Combinación de listas y diccionarios.
4. `14_filtro_duplicados.py`: Uso de conjuntos (`set`) para limpieza.
5. `15_generador_passwords.py`: Uso de librerías estándar (módulo `random`).
6. `16_validador_formatos.py`: Lógica avanzada de validación de cadenas (ej. correos).
7. `17_manejador_errores.py`: Control de excepciones (`try/except`).
8. `18_lector_archivos.py`: Apertura y lectura de archivos de texto (`open`, `read`).
9. `19_escritor_archivos.py`: Guardado de resultados en un `.txt` (`write`).
10. `20_buscador_palabras_txt.py`: Combinación de lectura de archivos y búsqueda iterativa.

### 🔴 Módulo 3: Difícil (Procesamiento y Algoritmos)
En este punto, los datos sueltos se convierten en información estructurada. Nos enfocaremos en extraer, transformar y cargar datos con precisión.
1. `21_extractor_regex.py`: Uso del módulo `re` para encontrar patrones específicos.
2. `22_lector_csv.py`: Parseo de archivos separados por comas.
3. `23_conversor_json.py`: Transformación de diccionarios a formato JSON y viceversa.
4. `24_calculadora_fechas.py`: Manejo del tiempo con el módulo `datetime`.
5. `25_filtro_avanzado.py`: Uso de *List Comprehensions* para procesar datos rápidamente.
6. `26_agrupador_categorias.py`: Algoritmo para clasificar listas de diccionarios según una llave.
7. `27_limpiador_datos_nulos.py`: Detección y eliminación de información incompleta en estructuras complejas.
8. `28_generador_estadisticas.py`: Cálculos de promedios y sumatorias sobre datos estructurados.
9. `29_recorredor_directorios.py`: Uso del módulo `os` para listar archivos en una carpeta.
10. `30_script_orquestador.py`: Ejecución secuencial y lineal de múltiples funciones pequeñas.

### 🚀 Proyecto Final: Automatización
**`proyecto_automatizacion.py`**
Un script de ejecución lineal diseñado para integrarse como herramienta de terminal. Toma todo lo aprendido para resolver un flujo de trabajo completo sin intervención manual.

## ⚙️ Entorno de Desarrollo

1. Clona este repositorio en tu máquina con Ubuntu.
2. Abre la carpeta directamente en tu entorno de trabajo (IDE de Antigravity).
3. Asegúrate de tener Python 3.x instalado en tu sistema.
4. Ejecuta cada archivo desde la terminal integrada de forma individual:
   ```bash
   python3 modulo_1/01_hola_tipos.py
